# GymTracker Pro — iOS App

This is the iOS-native build of **GymTracker Pro**, powered by [Capacitor](https://capacitorjs.com/) wrapping the existing Vite/React web app.

The app code is 100% shared with the web version — no rewrites needed.

---

## Prerequisites (Mac only for iOS builds)

| Tool | Install |
|------|---------|
| **Node.js** ≥ 18 | [nodejs.org](https://nodejs.org) |
| **Xcode** ≥ 15 | Mac App Store |
| **CocoaPods** | `sudo gem install cocoapods` |
| **Xcode Command Line Tools** | `xcode-select --install` |

> ⚠️ **iOS builds must be done on a Mac.** The `ios/` folder is fully generated here on Windows, but you need a Mac with Xcode to compile and sign the `.ipa`.

---

## Development Workflow

### 1. Install dependencies (one time)
```bash
npm install
cd ios/App && pod install && cd ../..
```

### 2. Build & sync web app to native
```bash
npm run sync
# Equivalent to: npm run build && npx cap sync
```

### 3. Open in Xcode
```bash
npx cap open ios
```
Then in Xcode: select your device/simulator → press **▶ Run**

---

## One-liner (build + sync + open Xcode)
```bash
npm run ios
```

---

## Rebuilding after code changes
```bash
npm run sync   # rebuilds web app and copies to ios/App/App/public
```
Then **Cmd+R** in Xcode to re-run.

---

## Publishing to App Store

1. In Xcode → **Signing & Capabilities** → select your Apple Developer Team
2. Set a unique **Bundle Identifier**: `com.hadisovic.gymtrackerpro`
3. **Product → Archive** → Upload to App Store Connect
4. Submit for review in [App Store Connect](https://appstoreconnect.apple.com)

## Project Structure

```
trackerapp/
├── src/                  ← React source (shared with web)
├── public/               ← Static assets
├── dist/                 ← Built web app (auto-generated)
├── ios/                  ← Native Xcode project (auto-generated by Capacitor)
│   └── App/
│       ├── App/
│       │   └── public/   ← Web assets copied here by `cap sync`
│       └── Podfile
├── capacitor.config.ts   ← Capacitor configuration
├── vite.config.ts        ← Vite build config (base: '/')
└── package.json
```
